# ALW Academy Telegram bot

## Админ-панель

В личном чате с ботом администратор с `ADMIN_ID` открывает `/panel` (также
работает `/admin`). В панели доступны сводки за 24 часа, 7 и 30 дней или всё
время, лента событий, пользователи с полной историей, источники входа, CSV
выгрузки, редактирование текстов воронки и рассылка.

Для атрибуции кампаний используй deep-link Telegram:

`https://t.me/<имя_бота>?start=src_instagram`

В отчёте источник будет показан как `instagram`. Для заявок в канал бот также
сохраняет название именованной invite-ссылки Telegram. Обычная URL-кнопка
Telegram не сообщает боту о клике, поэтому для неё фиксируется источник входа,
а не сам факт открытия ссылки.
